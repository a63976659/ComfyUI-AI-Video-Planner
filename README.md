# 视频规划师

**语言 / Language：** 🇨🇳 简体中文（当前） ｜ [🇬🇧 English](./README_EN.md)

一个 ComfyUI 插件，把一条长视频拆成若干小段分别生成，最后拼成完整视频。

生成能力全部来自 ComfyUI 官方的 MiniMax H3 节点，本插件只做「拆段 → 逐段跑 → 拼回去」的编排工作。

## 能做什么

- **把长视频拆成多段**：在时间轴上添加若干段，每段写自己的提示词、设自己的时长。
- **每段挑一种生成方式**：文字生视频、图片生视频、首尾帧生视频、参考素材生视频、视频改视频、参考素材+视频改视频，一共 6 种，段与段之间可以混着用。
- **每段挂参考素材**：图片、视频、音频都行，可以用 `<Picture 1>` 这种标签在提示词里点名引用。
- **段之间可以平滑过渡**：打开「渐变过渡」开关后，上一段末尾的画面和声音会带进下一段，接缝不突兀；关闭时每段独立生成。
- **跑过的段自动存下来**：每跑完一段就存到硬盘。下次再跑，没改动的段直接读回来，不重新生成，几十秒就能出片。
- **只跑勾选的段**：每段下面有个「运行」开关，勾了才重新生成；没勾但之前存过的段照样会拼进最终视频。

## 怎么用

### 第一步：把节点连上

在工作流里添加节点 **长视频规划师**（node_id `长视频规划师`）。

它有 5 个输入口：

| 输入口 | 说明 | 是否必填 |
|---|---|---|
| `fl2va模型` | 文字/图片生视频用的模型 | 选填，用到才连 |
| `ref2va模型` | 参考素材生视频用的模型 | 选填，用到才连 |
| `CLIP编码器` | 文字编码器，必须是 minimax 类型（Qwen3-VL） | 必填 |
| `视频VAE` | 视频解码器 | 必填 |
| `音频VAE` | 音频解码器 | 必填 |

上面两个模型口，用哪种任务连哪种就够了；两个都用就都连上。

节点输出：图像、音频、帧率、总帧数、报告文字，直接接 `SaveVideo` 或 `PreviewVideo` 就行。

### 第二步：打开底部状态栏

插件加载后，ComfyUI **页面底部**会自动出现一条「长视频规划师」面板，里面有：

- **生成类型**：切换 6 种任务
- **画风预设**：从下拉里选一种画风，正文自动填进全局提示词
- **提示词编辑框**：写全局提示词，会加在每一段的前面
- **参考素材区**：上传图片/视频/音频，重复上传会自动去重
- **时间轴**：主要工作区

节点上对应的输入框会自动隐藏，所有数据都存在节点里，状态栏只是编辑器。

### 第三步：编辑时间轴

- **加一段**：点轨道空白处，或者点「+」按钮
- **改时长**：拖段卡的左右边缘，或者用段卡下方的时间输入框
- **勾/不勾运行**：段卡下方那个开关。勾了才重新生成；不勾但之前存过就直接用旧的
- **改提示词、挂参考素材**：点段卡进去编辑
- **播放头**：拖动可以看到某个时间点在哪一段
- **渐变过渡**：时间轴工具条上的开关，打开后段与段之间会平滑衔接

时间轴数据以 JSON 形式存在节点的 `时间轴数据` 输入框里，可以复制粘贴，方便存档和分享。

### 第四步：点 Queue Prompt 开始生成

生成过程分两步：

1. **先一段一段跑采样**，每段跑完立刻存到硬盘（每段大约 45 MB）
2. **全部段都跑完后再统一解码、拼接**成最终视频

这么拆是为了让显卡在解码时能空出来，不然 16GB 显卡跑高分辨率长段时会慢十几倍。

底部状态栏会显示「生成中 3/7」这样的段级进度。

## 中途取消或报错怎么办

已经跑完的段**不会丢**，它们已经存到硬盘上了。

正在跑到一半的那段**会丢**，下次要重新跑。

如果你只想拿到已跑完的那些段：

1. 打开时间轴面板
2. 把没跑完的段、以及后面还没轮到的段的「运行」开关**全部关掉**
3. 只留下已经跑完的段的开关是勾上的（其实关掉也行，只要有缓存都会拼进去）
4. 再点一次 Queue Prompt

这次跑会全部命中缓存，几十秒就能出片。控制台报告里会写「段N: 命中缓存」，说明这一段是直接从硬盘读的。

## 硬件要求

| 项目 | 建议配置 |
|---|---|
| 显卡 | 显存 12GB 起步，16GB 更稳 |
| 内存 | 32GB 起步（拼接阶段吃内存） |
| 硬盘 | 预留 5GB 以上给缓存 |
| ComfyUI | 支持 V3 节点 API，且带 MiniMax H3 官方节点 |
| 模型 | MiniMax H3 主模型 + Qwen3-VL 编码器 + 视频 VAE + 音频 VAE |

## 安装

**方式一：git clone（推荐）**

```bash
cd ComfyUI/custom_nodes
git clone <本仓库地址> ComfyUI-AI-Edit-Video
```

**方式二：手动放**

下载压缩包解压，把整个目录放到 `ComfyUI/custom_nodes/ComfyUI-AI-Edit-Video/`，重启 ComfyUI。

**可选依赖**（在 `requirements.txt` 里取消注释后再 `pip install -r requirements.txt`）：

- `imageio` + `imageio-ffmpeg`：读取参考视频（用到 r2v/v2v/rv2v 才需要）
- `scenedetect` + `opencv-python-headless`：源视频自动分段（用到智能分镜才需要）
- `pytest`：跑单元测试

**验证装好了**：

- ComfyUI 启动日志里能看到 `[长视频规划师]` 开头的行
- 节点搜索框输 `长视频规划师` 能找到主节点
- 页面底部有长视频规划师面板

## 注意事项

**缓存放在哪**

默认在 `%TEMP%/长视频规划师_段缓存/`。想改位置就设环境变量 `长视频规划师_段缓存_DIR`。

老版本的缓存目录会在插件启动时自动删掉，不用手动清理。

**分辨率怎么算**

由「输出分辨率」（选宽高比）和「百万像素」（选画面精细度）两个 widget 共同决定。默认 `0.4 百万像素 + 16:9` 出来是 **864×480**。

百万像素调得越大越吃显存，`4.0 + 21:9` 会到 3136×1344，量力而行。

**帧率是什么意思**

节点上的「帧率」输入框只是给输出视频文件打的标签，实际生成时用的**永远是每秒 24 帧**（官方模型的固定值）。想让视频慢放/快放，改帧率数字就行；想改真实运动速度，改段的时长。

**段之间怎么衔接**

「渐变过渡」开关控制：

- **关**（默认）：每段独立生成，接缝处只有 4 帧交叉淡化
- **开**：上一段末尾 22 帧的画面和声音会带进下一段，接缝更自然，但也更容易出问题

如果出现花屏、幻影、鬼影，先把「渐变过渡」关掉试试，看是不是模型本身的问题。

**换了 checkpoint 之后**

老的段缓存不会自动作废。想让所有段重新按新模型跑一遍，需要手动删掉 `%TEMP%/长视频规划师_段缓存/` 目录下当前版本对应的子目录。

**只连了一个模型口能跑吗**

能。插件只会检查你**当前时间轴用到的任务**对应的模型有没有连，没连的话会明确报出来「哪个任务缺哪个模型」，其他情况都不管。

**音频出问题会有提示**

如果某一段没有音频而其他段有（比如中途才连上音频 VAE），拼接时视频段全都要，音频段会跳过缺的那些。这种情况报告会多一行警告「音频段数 < 视频段数，A/V 可能错位」，看到就要注意成片可能音画不同步。

## 更新记录

**2026-09-15**

- 生成分两步：先一段一段跑采样存到硬盘，全部跑完后再统一解码拼接。修好了 16GB 显卡跑高分辨率长段时解码从 52 秒变成 839 秒的问题。
- 段之间的衔接不再走「解码 → 重新编码」这条路，直接从上一段的中间产物切一段下来用，接缝更保真。
- 拼接改成边解码边往预分配的成片缓冲里写，峰值内存从 3 段的量降到 1 段多一点。
- 修：有段被跳过又没缓存时，进度条到不了 100%。
- 修：后台计时日志里「参考解码」耗时永远显示 0.00 秒的统计问题。
- 修：上下文帧数调到 1~4 之间时接缝处会多重复 4 帧画面。
- 缓存改成按版本分子目录存放，插件启动时自动删旧版本目录。彻底解决了以前升级后老缓存变成永远读不到的死文件、堆在临时目录没人清（曾经积到 27.9 GB）的问题。今后升级不用再手动清缓存。
- 底部状态栏的段级进度（「生成中 3/7」）之前从来没真正显示过，收到的全是采样器内部几十步的去噪进度，看起来在乱跳。现在改走插件自己的通道，段级进度真实可见。
- 加固：缓存文件如果被外力改坏（帧数和实际数据对不上），现在当场判为无效并重算，不会拖到解码拼接阶段才炸——那样已经跑了几小时的采样就白费了。
- 单元测试从 196 个增加到 217 个，全部通过。

**2026-09-14**

- 节点改成两个可选模型接口，按每段任务自动选对应的模型，不用手动切。
- 运行前只检查时间轴实际用到的模型有没有连，缺哪个报哪个。
- 两个模型的缓存分开保留，混合任务不再反复重载。
- 调整节点接口排列顺序，编码器显示在最前。
- ⚠️ 旧工作流需要重新连模型线、核对两个隐藏开关，老缓存会作废一次。

**2026-09-13**
