# H3 确认图模版

> 说明：模版中的 `{占位符}` 在运行时填充；UI 上需要渲染的按钮文案（如 CONTINUE、START NEW GAME）保持英文。

## 核心规则

为合作游戏主菜单生成一张精修的 16:9 横版确认图。
画面由两个独立系统构成：
• UI 框架（固定）
• 视觉风格（动态）
UI 框架定义布局、构图、信息层级、交互逻辑、阅读动线、菜单结构和可读性。这些元素必须保持不变。
{visual_style} 只控制艺术外观，包括渲染媒介、材质、色彩语言、光影氛围、环境风格、角色设计、服装语言、UI 材质、图标语言、字体外观、装饰纹样和整体氛围。
更换 {visual_style} 应像给同一个专业设计的游戏菜单套用不同的美术方向，而不是重新设计界面本身。
如果任何默认描述与 {visual_style} 冲突，优先 {visual_style}，同时保留 UI 框架。

---

## 设计目标

创作一张 16:9 横版的高级商业主机游戏主菜单概念图。画面应兼具精修游戏宣传画的品质与专业游戏 UI 的清晰度。角色与界面必须感觉自然融合，具有强视觉层级、优秀可读性、干净构图和明确的交互焦点。

---

## 整体风格

遵循用户选择的视觉风格：{visual_style}。
所选风格控制渲染媒介、插画风格、材质、色板语言、环境、角色外观、服装设计、UI 外观、图标语言、字体处理、装饰元素和氛围。
所有视觉元素必须属于同一套统一的艺术语言。
不要在同一画面中混搭不兼容的视觉风格。
无论风格如何，UI 框架、布局、层级、构图和交互逻辑必须保持一致。

---

## 色彩系统

整套色彩系统从 {visual_style} 推导。
使用：
• {main_background_color} 作为主背景色。
• {ui_body_color} 作为 UI 主体色。
• {text_color} 作为主文字色。
• {functional_accent_color} 作为交互强调色。
• 红色仅用于警告、危险或退出动作。
整体色板限制在五种主色以内。
所有按钮、玩家卡、图标、边框、高亮、装饰元素、字体和视觉效果必须遵循同一色彩系统。
避免引入所选色板之外的无关颜色。

## 构图

使用固定的 16:9 横版布局。
将 {character_count} 名可操作角色置于画面中央作为视觉主体。
UI 环绕角色但不遮挡角色。
玩家信息卡放在左上角。
主菜单纵向放置在右侧。
底部放置一条装饰性横条，自然适配 {visual_style}（如丝带、警戒带、木板、石板、能量条、卷轴等）。
保持清晰的 Z 字形阅读动线：
玩家卡 → 角色 → 菜单 → Continue 按钮。
Continue 按钮必须始终是首要视觉焦点。
保持充足的留白和优秀的可读性。

---

## 背景

生成自然源自 {visual_style} 的背景。
背景应衬托界面，而不是与界面争夺注意力。
在所有重要 UI 元素背后保留足够干净的留白。
只在适合所选风格的地方使用细微纹理、环境细节和装饰纹样。
避免过多视觉噪声、密集装饰、厚重脏污、划痕、油漆飞溅或干扰性纹理。
整体背景应感觉精修、高级、现代，适合商业游戏菜单。

---

## 角色风格

所有角色严格遵循 {visual_style}。
所选风格决定：
• 渲染媒介
• 身体比例
• 面部风格化
• 服装语言
• 材质处理
• 光影响应
• 动画风格
• 整体角色品质
只有角色身份锚点和姿态保持固定。面部渲染、眼睛设计、鼻子简化、嘴形、皮肤处理、表情风格和头部比例必须完全按 {visual_style} 重新诠释。
任何默认角色风格都不得压过 {visual_style}。

## 按钮布局规则

所有菜单按钮纵向放置在右侧。
保持一致的纵向节奏。
每个按钮使用同一设计家族。
按钮宽度自动适配文字长度。
所有菜单标题保持单行。
不自动换行。
不堆叠文字。
文字保持水平居中。
保持一致的内边距。
按钮之间保持等间距。
避免视觉杂乱。

可能的强调手法包括：
• 更大尺寸
• 更强对比
• 更亮颜色
• 独特材质
• 特色边框
• 灯光
• 辉光
• 雕刻
• 魔法能量
• 全息效果
• 浮雕边框
• 动态视觉提示
如果辉光或霓虹与 {visual_style} 冲突，不要强行使用。
Continue 按钮应立即吸引玩家注意。

不改变发型。
不要无法阅读的 UI。
不要扭曲的按钮。
不要重叠的界面。
不要随机文字。
不要随机符号。
不加水印。
不复制游戏 Logo。
不使用品牌化界面。
不要图标风格不一致。
不要 UI 材质混搭。
不要过度装饰。
不要喧宾夺主的背景。
