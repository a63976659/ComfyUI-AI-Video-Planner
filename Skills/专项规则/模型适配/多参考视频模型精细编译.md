# 多参考视频模型精细编译

## 执行细则

1. 读取实际选中的目标模型能力配置：任务、可用素材类型与槽位、时长、画幅、音频、分时段控制等。不能把资料中的示例参数当作供应商已验证能力。
2. 输入是已经定稿的中性分镜、锁定声音文本、真实素材映射和起止状态。编译只转换表达格式，不重新编故事、台词、时长、画风和素材绑定。
3. 先按主体、环境、动作链、摄影机、声音与衔接组织自然语言，再按目标模型已确认支持的引用与时间表达编译。只引用实际输入的文件，不虚构多参考、角色标签或未注册参数。
4. 多角色、多动作或时间控制超出能力时先保持分镜并报告不兼容；规划范围内直接确定可执行结构，编译阶段不改变已定分镜。
5. 校验主体归属、声源、时间范围、素材槽位和原文事实，未知模型能力一律不承诺。生成前落实全部编译要求，保留增量复用；格式变化只使相关提示词失效。

## 输出要求

具体记录：目标模型与能力依据、主体素材映射、动作与时间编译、声音归属、禁止更改项、兼容诊断。

## 正反示例

可用方案：同一已确定6秒镜头按所选模型实际支持的自然语言与图片引用编译，剧情和时长不变；未确认功能明确不输出。

错误方案：未核验就强制30秒、多参考和特殊标签，或为适配模型重新改写胜负。
