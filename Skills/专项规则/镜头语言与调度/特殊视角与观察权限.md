# 特殊视角与观察权限

## 执行细则

1. 先决定是谁在看以及观众应获得什么。主观视角必须来自已建立的人物位置与朝向，不能用主观镜头透露角色不知道的事件。
2. 高低机位表达尺度、风险或受限视野，同时检查能否看见必要动作。虫视、贴地、极高俯拍不能只为变化加入，也不改变人物世界位置。
3. 建立视线镜头与被观察对象的对应。越过障碍、穿过封闭空间或不可能高度时写成创意拍摄意图，并按生成能力简化。
4. 特殊角度会改变透视、遮挡和空间线索。保留至少一个可识别地标或前后镜定位，避免特殊角度串联使人分不清目标与路线。

## 输出要求

具体记录：观察者、观察位置、角度目的、可见信息、遮挡与定位线索。

## 正反示例

可用方案：躲在桌下的孩子视角只见到门口来人的鞋与停下的脚步，保留桌腿作为空间锚点。

错误方案：角色未看见的背后事件被写成他的主观视角。
