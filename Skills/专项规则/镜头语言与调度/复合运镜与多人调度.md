# 复合运镜与多人调度

## 执行细则

1. 先画出世界空间中的连续行动路径，再写摄影机路径；分开主体路线、摄影机路线和其它角色进出时间，不能混成一句绕场跟拍。
2. 为连续镜头分起点、节点与终点：每个节点说明观察对象、揭示内容、遮挡、速度变化与重新接管的对象。控制同时发生的动作数量。
3. 核对门宽、通道、障碍、高低差、旋转幅度与角色交汇；镜头不能无解释穿越实体，角色也不能为配合镜头瞬移。
4. 按执行段时长估算行走与观察节点。无法容纳时拆成有动机的连续镜头，并记录动作接续；不给不支持的模型保证精确长镜头与秒级机位控制。

## 输出要求

具体记录：空间节点、人物进出、摄影机起点路径终点、跟随交接、时间与简化方案。

## 正反示例

可用方案：镜头先跟店员到柜台，在他放下包裹时转向接过包裹的客人，最终停在客人查看封口的手边。

错误方案：30秒复杂走位塞入短段，只写一镜到底高级环绕且没有路线。
