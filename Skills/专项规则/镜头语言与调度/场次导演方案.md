# 场次导演方案

## 执行细则

1. 先将场次目标、人物关系和空间结构转成观看任务，再确定覆盖方式、机位、运动与切镜依据；不要从随机景别列表开始。
2. 依据用户约束和实际素材形成一套自洽方案。自动流程将方案保存为后续依据，不引入手选菜单或每场确认；后续改写不得重新导演。
3. 检查信息分配、动作可读、时长与生成能力。方案允许克制固定镜头，也允许有动机的运动，不能机械要求每镜不同。
4. 生成前落实具体拍法与质量要求，保留已确定的剧情、台词、素材职责与手工编辑。

## 输出要求

具体记录：场次观看任务、覆盖策略、机位与运镜、切镜理由、设计依据及已确定安排。

## 正反示例

可用方案：先以中景交代门与桌的位置，之后仅在人物态度改变时切反应，镜头数量来自事件。

错误方案：先凑满镜头数，再给每镜随机分配推拉摇移和情绪标签。
