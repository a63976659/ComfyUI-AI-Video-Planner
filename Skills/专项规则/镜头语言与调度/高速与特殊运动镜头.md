# 高速与特殊运动镜头

## 执行细则

1. 确定特殊运动带来的观察价值，例如呈现路径、尺度、压迫或接近关系，不以速度和旋转本身作为目的。
2. 明确起点、对象、路径、终点、遮挡和可识别地标，主体运动与摄影机运动分开，避免两者同时复杂导致看不清。
3. 特殊高度、加速和绕行必须与场景几何及行动条件相容。无法可靠生成的运动作为意图记录并自动简化，不承诺精确物理摄影机轨迹。
4. 速度感可以来自主体经过地标、适当观察距离与方向连续，不强制模糊或快切。保留接触结果和人物身份，不让运动抹去剧情。

## 输出要求

具体记录：运动目的、路线速度、观察对象、地标遮挡、能力限制及简化方案。

## 正反示例

可用方案：低机位跟随车轮经过已建立的巷口，在转弯前留下目标路线的空间线索。

错误方案：镜头穿墙穿人高速环绕，主角和目标在哪都看不清。
