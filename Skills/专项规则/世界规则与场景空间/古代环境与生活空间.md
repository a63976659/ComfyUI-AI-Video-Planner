# 古代环境与生活空间

## 执行细则

1. 先确定时代依据或架空规则，再梳理地点功能、出入口、通道、区域与人物活动。建筑名称不能代替可使用的空间。
2. 保持材料、道路、器具、照明和生活方式自洽；未指定细节确定自洽的造型并标为规划补全，不能把不同朝代的形制随意混合后声称历史准确。
3. 在每个常用场景设置少量固定地标，如门、窗、台阶、工作台，并给出相对位置。人物路线、机位和光源都引用这些锚点。
4. 生活物件服务人物和剧情；不要为了古风堆满灯笼、红纱、烟雾和摆设。换场时重新建立位置，回到旧场景沿用同一状态记录。

## 输出要求

具体记录：时代性质、地点功能、区域出入口、固定地标、材料生活物件和依据。

## 正反示例

可用方案：小客栈先确定门、柜台、楼梯与后院关系，追逐和对话都沿用这套布局。

错误方案：同一客栈门窗、楼梯与太阳方向随切镜漂移，只有古风二字不变。
