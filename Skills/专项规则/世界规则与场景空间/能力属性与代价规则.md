# 能力属性与代价规则

## 执行细则

1. 建立能力的来源、触发条件、作用对象、范围、持续、终止和代价；这些是故事内规则，不冒充现实科学结论。
2. 能力表现、人物选择和局势变化相互关联。颜色不等于属性机制，不能只把同一光团改成红蓝紫。
3. 相克、抵抗、反制和失效需要原文或本次已确定的授权创作设定支持。没有依据不能临时赋予无敌、复活、吸收一切或突破边界。
4. 记录使用前后人物体力、装备、环境与持续效果。每个镜头延续同一规则，效果消失需要触发或时间依据。

## 输出要求

具体记录：来源触发、对象范围、视觉表现、限制代价、反制依据、结束状态。

## 正反示例

可用方案：冰障只封住既定通道并短时阻挡，融化后地面状态仍影响后续行动。

错误方案：角色陷入困境后能力无限升级，上一镜代价在下一镜完全消失。
