# 跨题材地点共存

## 执行细则

1. 分别列出两种设定中已被允许的建筑、技术、生活与超自然要素，再说明它们在同一地点怎样共存。
2. 技术和能力必须有空间后果：装置占什么位置、由谁使用、怎样影响动线；不只是给古城贴霓虹灯或给现代楼加庙宇顶。
3. 为材质、结构、色彩与光源建立统一逻辑，限制重复元素数量。美术变化不能改变原文交通、地理和人物可达区域。
4. 镜头切换维持同一地点规则；涉及不同区域或时代时显式交代，不把风格漂移包装成混合题材。

## 输出要求

具体记录：共存机制、区域分工、技术与生活关系、统一视觉规则、空间限制。

## 正反示例

可用方案：古城内通信塔集中在驿站，日常街巷仍按既定生活方式运行，人物去驿站才能发送消息。

错误方案：每个镜头换一套时代与建筑，没有任何共存规则。
