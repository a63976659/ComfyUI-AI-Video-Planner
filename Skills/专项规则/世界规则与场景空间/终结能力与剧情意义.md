# 终结能力与剧情意义

## 执行细则

1. 先确定终结动作为什么发生、人物付出什么、它改变哪项局势；胜负和代价符合原文或已确定的授权创作设定，不以画面规模替代剧情意义。
2. 把准备条件、蓄势、释放、遭遇抵抗与结果分别说明，判断哪些节点必须可见，哪些可连续发生；不强制所有招式都套五个镜头。
3. 威力尺度与既定能力层级一致。人物与空间仍保持可识别的尺度锚点，不能突然改变战场大小或增加无依据毁坏。
4. 检查动作、观察与反应能否容纳在段时长中。必要时拆镜并维护状态，不让最长时长限制把关键因果压没。

## 输出要求

具体记录：剧情触发、准备条件、力量尺度、代价、对抗结果和所需节拍。

## 正反示例

可用方案：主角用已建立的短时护盾替同伴争取离开时间，高潮是选择与代价而非爆炸大小。

错误方案：只写释放灭世大招，既没有准备也没有抵抗，更改了原本的结局。
