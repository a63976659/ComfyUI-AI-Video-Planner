# 真人行为与生活节奏

## 执行细则

1. 先从人物目标、注意对象和现实任务找行为，再决定情绪强度。不要默认通过瞪眼、攥拳、喘气和流泪表达一切。
2. 用有原因的动作幅度、观察、犹豫、试探和未完成动作承载变化；不强加每镜微表情或随机小动作。
3. 角色听见、理解、作决定和行动需要可解释的先后与时间；表演留白不等于生成卡住，停顿要有明确注意对象。
4. 情绪、身体状态和关系保持连续，突然改变需事件触发。尊重用户夸张或风格化要求，不将真人尺度强加到所有动画。

## 输出要求

具体记录：行动目的、注意对象、幅度节奏、反应延迟、事件触发与风格限制。

## 正反示例

可用方案：听者先看一眼桌上的车票，再抬头回答；迟疑由新信息引发，而不是循环摆动。

错误方案：所有人物持续眨眼摇头，任何台词都伴随夸张手势。
