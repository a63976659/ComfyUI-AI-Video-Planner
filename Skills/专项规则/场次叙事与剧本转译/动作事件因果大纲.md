# 动作事件因果大纲

## 执行细则

1. 在拆镜之前写清发起行动的原因、行动目标、应对、局势变化和结果。招式清单不是剧情大纲。
2. 动作数量由事件所需决定，不能为了展示技法新增伤势、武器或胜负。保真锁定的结果优先于视觉炫技。
3. 把位置、障碍、距离与持物作为因果条件；动作结果必须反过来更新这些状态，不让环境只作背景。
4. 为准备、行动、应对、结果和必要反应估时，明确并行与先后。超预算优先拆解事件，不能把整段战斗写成一句激烈交锋。

## 输出要求

具体记录：发起原因、目标、应对、局势变化、结果状态、节拍时间。

## 正反示例

可用方案：追赶者为拦住去路先到门边，逃离者改变方向，双方位置变化推动下一段追逐。

错误方案：人物连续摆招式，没有人有目标，也没有任何动作造成结果。
