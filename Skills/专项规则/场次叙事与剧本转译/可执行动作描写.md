# 可执行动作描写

## 执行细则

1. 将笼统动作拆成行动者、目标、准备、主动作、接触或未接触、结果与反应；不以招式名称替代可见过程。
2. 明确身体支撑、运动方向、相对距离、障碍与持物状态。身体变化和环境结果必须符合既定故事规则，而非镜头需要时凭空变化。
3. 动作描写仍是剧情和表演资料，不提前输出视频模型语法。胜负、伤情、武器与能力按共用创作范围确定，不因动作优化临时改变已定设定。
4. 动作越多不等于越专业；按单段能力和时间保留少量清晰因果，复杂群体或顺序动作拆镜并维护边界。

## 输出要求

具体记录：行动目标、准备主动作、接触与受力、结果反应、空间与时间。

## 正反示例

可用方案：人物跨一步接近，抬手挡住对方推来的手臂，随后退到椅旁；椅子状态不变。

错误方案：只写双方打得惊天动地，动作顺序、接触和结果全部缺失。
