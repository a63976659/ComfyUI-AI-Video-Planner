# 入出场与调度动线

## 执行细则

1. 先建立场景入口、出口、可停留区域与人物初始位置，再规划谁因何进入、离开、靠近或避让。
2. 每次移动服务具体任务，例如取物、拦住通道、避开视线或接近说话者；不让所有角色无理由来回走动。
3. 把世界方向、朝向、视线目标与机位观察分开。角色出画不等于离开场景，必须记录他停留在哪个区域。
4. 检查多人路线交汇、遮挡、道具交接与动作时间；复杂调度先拆成少量可见动作，不以人物跳位置解决镜头构图。

## 输出要求

具体记录：初始区域、出入口、移动任务、路线终点、出画状态、观察机位。

## 正反示例

可用方案：弟弟从门边走到桌旁取杯子，姐姐让出通道；下一镜两人位置依据这次移动更新。

错误方案：对话一切镜，两个人直接交换左右和持物，没有任何移动或交接。
