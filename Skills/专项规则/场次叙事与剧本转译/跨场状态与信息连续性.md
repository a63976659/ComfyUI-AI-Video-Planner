# 跨场状态与信息连续性

## 执行细则

1. 建立人物外观、服装、伤势、持物、地点、时间、已知信息与未解伏笔状态；事实必须能追溯到原文或已确定的授权创作资料。
2. 每场写入发生的状态变化，后一场从相应结束状态接续；画面方向变化须结合机位与地标，不把屏幕左右单独当成穿帮。
3. 物件交接要有谁、何时、从哪里到哪里；角色获知秘密也要有信息来源，不能在下一场无解释知道全部事实。
4. 换场、跳时与回忆使用明确状态记录。文本检查只能证明计划是否自洽，生成后的实际外观和动作仍需视觉观察。

## 输出要求

具体记录：开始状态、事件变化、结束状态、信息权限、物件交接、证据范围。

## 正反示例

可用方案：角色把钥匙放进外套口袋后离开，下一场取钥匙时沿用同一口袋与外套状态。

错误方案：人物上一场未听见秘密，下一场却无原因解释秘密全部内容。
