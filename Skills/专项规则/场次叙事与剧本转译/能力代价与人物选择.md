# 能力代价与人物选择

## 执行细则

1. 每次能力使用连接人物此刻的目标与取舍，说明为何不用其它已知办法；能力不是自动解决所有矛盾的按钮。
2. 效果大小、持续与代价服从已建立的规则。使用前条件、对方应对和结束后的身体环境状态都须进入正式事件线。
3. 角色选择推动结果，不能只有特效替角色完成戏剧任务。保真时原文胜负、伤情和关键后果必须原样保留。
4. 将无关视觉花样削减为服务因果的少量变化；能力描写应可拆成有限节拍，不用烟花般效果掩盖行动不成立。

## 输出要求

具体记录：选择理由、能力条件、代价承担者、对抗、结果与持续后果。

## 正反示例

可用方案：人物选择把有限防护留给同伴，自己的下一场动作受这次消耗限制。

错误方案：释放大招不付代价，打完双方状态归零，原文失败却被改成获胜。
