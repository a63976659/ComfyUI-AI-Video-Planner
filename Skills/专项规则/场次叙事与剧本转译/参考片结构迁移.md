# 参考片结构迁移

## 执行细则

1. 只根据实际提供的片段、观察记录或可靠时间轴分析结构，区分完整观看与离散抽帧；未知事件和精确节拍不能靠文件名推测。
2. 提取定位、期待、信息揭示、反应与结束等叙事任务，以及它们的先后与相对停留；不复制参考的人物、台词、情节和品牌。
3. 将这些任务映射到当前内容的真实事件，保留用户体裁、风格、时长与禁令。安静作品不必继承参考的高密度钩子。
4. 无法建立对应的镜头不强行补造，写出未采用理由。结构借鉴与素材使用分开，授权不明确的原画面不得默认进入成片。

## 输出要求

具体记录：观察范围、结构任务、当前事件映射、未采用项、素材与授权限制。

## 正反示例

可用方案：借鉴先见到结果再揭示原因的组织方法，但所有角色、对白与因果都来自当前剧本。

错误方案：看到几个抽帧就声称精确拆出了整片所有切镜与配乐节拍。
