# 人物语气与防御方式

## 执行细则

1. 为每个说话人确定关系、当场欲望、知道的信息和防御方式。语气由当前情境变化，不是姓名固定对应一种声调。
2. 创作模式下通过句式长短、直接程度、词汇选择和回应策略区分人物；保真模式保持原话，以音量、音高、独立停顿、重音和身体行动表现差异。
3. 同一个人物对不同对象可以改变说法，同时保持身份连续。不要以职业、性别、地区强制刻板口音或道德特征。
4. 检查台词是否真正回应前句与可见事件，旁白不让画内人物随意对口型；当前能力无法生成指定音色时标为声音意图。

## 输出要求

具体记录：说话人、对象关系、信息权限、表达策略、停顿重音与可见行为。

## 正反示例

可用方案：一人直接询问去向，另一人先整理衣袖再回避回答，差异来自关系与目标而非随机口音。

错误方案：换了角色名字，每人仍以同样节奏背诵同一类解释段落。
