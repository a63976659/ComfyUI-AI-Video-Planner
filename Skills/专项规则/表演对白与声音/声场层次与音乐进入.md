# 声场层次与音乐进入

## 执行细则

1. 分开对白、旁白、环境、动作声、音乐与留白，明确每层声源和叙事职责。没有实际音轨时只做设计，不推断听到的内容。
2. 画内声与可见动作匹配，画外声有合理空间来源。不能把声景再次写成完整对白，造成模型重复说话或配音重叠。
3. 音乐进入、退出和强弱变化由场次任务决定，不默认全程铺满；环境安静也可以支持动作和倾听，不强加配乐。
4. 声音连续意图与执行能力分开，跨段声桥、词级同步、准确节拍需真实音轨和制作支持。用户禁令与字幕开关不等同于声音开关。

## 输出要求

具体记录：声层与来源、时间意图、音量前后关系、留白、素材需求和能力限制。

## 正反示例

可用方案：门外脚步先吸引人物注意，开门后环境声更清楚；不另外复述镜头已记录的对白。

错误方案：所有段统一铺激昂音乐，声景里又重复角色刚说过的台词。
