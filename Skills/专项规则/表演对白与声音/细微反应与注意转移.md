# 细微反应与注意转移

## 执行细则

1. 先确定人物看见或听见什么，再决定注意转移、停顿、视线和身体反应；微表情必须由事件触发，不是每镜强加的装饰。
2. 只保留有意义且当前景别能看清的细节。远景重点是身体行动，特写可以表现手部或视线，不能用看不见的面部细节代替可见动作。
3. 区分发音时呼吸、独立停顿、动作和倾听反应，时间不要重复计算。情绪强弱服从人物与画风，不以大幅度反应制造效果。
4. 反应的开始和结束连接前后状态；身份、持物和注意对象保持一致，不让短暂反应变成循环待机动作。

## 输出要求

具体记录：刺激来源、注意对象、可见反应、景别可读性、独立时间与结束状态。

## 正反示例

可用方案：角色看到空的座位后视线停住，手中茶杯放低；反应由可见空位触发。

错误方案：人物每句台词都瞪眼、深呼吸、流泪，没有事件原因。
