# 对白与关系变化覆盖

## 执行细则

1. 按信息、人物选择和关系变化分解观看任务，不机械一句台词一镜，也不把所有对白塞进同一短镜。
2. 先确保说话人与听者的空间关系，决定什么时候看说话者、什么时候看反应、什么时候保留双人关系。反应镜头要有新意义。
3. 对白与旁白保持原文本和声音归属；画外旁白不能让画内角色随意对口型。连续说话允许跨镜头，但不能重复同句或遗漏关键句。
4. 景别、切镜和运镜服从具体信息，给必要倾听和停顿时间。场次结束状态与后续动作保持连贯，无新信息时可保留固定机位。

## 输出要求

具体记录：说话与反应任务、覆盖顺序、声音归属、台词分配、关系变化和时间。

## 正反示例

可用方案：说话者提出请求时保留双人中景，听者看向门口后切其反应，表示新的选择。

错误方案：把两句同一意思的对白各拍一遍，或者反应者无端逐镜微笑。
