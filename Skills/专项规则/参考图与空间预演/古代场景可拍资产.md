# 古代场景可拍资产

## 执行细则

1. 将场景名称展开为功能区、出入口、结构层级与人物行动需要。建筑与物件依据时代或架空规则，不混用未经核实的历史名词。
2. 选择必须可见的生活物件、工作区与固定地标，保持少而清晰。可拍性取决于机位、通道与行动空间，不在于装饰数量。
3. 为实际会使用的视角提供空间信息，反打和侧面必须共享同一布局；不要每次给大殿、街道重新设计。
4. 参考图的风格、材料、时间与主光统一，图中准确牌匾和长文字使用真实素材或后期需求，不能声称生成文字必然正确。

## 输出要求

具体记录：时代依据、结构区域、生活物件、可用机位、主光、图像观察。

## 正反示例

可用方案：庭院图明确正门、树、廊与台阶，人物走到廊下避雨的路径在图中可见。

错误方案：生成一个装饰繁复却没有可用出入口和站位的大殿。
