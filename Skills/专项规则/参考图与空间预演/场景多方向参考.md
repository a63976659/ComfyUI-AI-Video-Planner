# 场景多方向参考

## 执行细则

1. 先给场景固定地标、区域、入口、主光和材料，再为各观察方向指定机位位置与观看对象，不随机生成九个不同房间。
2. 多方向视图覆盖场景建立、主要行动区、出入口与必要反打位置，数量按空间任务选择；九宫格只是预览布局，不自动等于九镜成片。
3. 检查相邻视图中的门窗、桌椅、道路与灯光是否属于同一世界空间。屏幕左右允许因机位改变而变化，物体真实位置不能漂移。
4. 每个有效视图保留机位与用途，必要时分开保存。无法确认的区域不写成已建模几何，更不能以图像连贯性替代精确三维坐标。

## 输出要求

具体记录：场景地标、机位方向、视图用途、光材质状态、实际观察、独立素材。

## 正反示例

可用方案：大殿建立图展示门与主台，侧向视图保留同一柱列和窗光，反打图交代入口而非新造大厅。

错误方案：九格全部写大殿电影感，门窗和柱子每格重新排列。
