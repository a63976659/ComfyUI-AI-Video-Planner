# 白模与站位空间草图

## 执行细则

1. 从明确的空间锚点、人物位置和主动作生成简化空间预演；只保留必要体块、通路、遮挡与观察方向，先解决空间再装饰。
2. 标注与生产图分开，图像模型的草图不等于精确三维建模。没有尺寸、坐标和实际几何时不得宣称碰撞、透视或摄影机轨迹精确通过。
3. 检查相对前后、出入口、可见动作、人物路线和机位通路。遮挡关键事件或通道不成立时优先修改机位或简化调度，不能让人物穿透物体。
4. 保真情节、身份和物件保持不变。白模只作构图与空间参考，不替代写实身份图，不默认把白模材质和铅笔线条带入成片。

## 输出要求

具体记录：空间任务、体块地标、人物路线、机位、遮挡、预演证据范围和已确定空间安排。

## 正反示例

可用方案：双人站位草图用门、桌和两个人形交代谁挡住出口，摄影机位于桌侧能同时看见双方。

错误方案：漂亮白模没有门与通道关系，却声称整场动作和轴线都已经验证。
