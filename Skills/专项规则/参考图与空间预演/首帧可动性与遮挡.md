# 首帧可动性与遮挡

## 执行细则

1. 实际观察首帧中的人物姿态、持物、接触、遮挡、画幅和可移动空间，不凭设定图想象任意起始动作。
2. 微动优先选择当前姿态支持的呼吸、视线、衣物或环境变化；动作幅度服从任务，不自动要求人物大步走出固定构图。
3. 关键主体被裁切、手部被遮挡或背景没有路径时，生成前确定可成立的动作范围；匹配构图的新首帧作为独立任务需求，不自动追加生成。不能让静态身份卡承担复杂动作起点。
4. 保护主体结构和场景地标，禁止整图液化般变形作为运动。静图不含声音证据，不能从嘴型猜出台词或声源。

## 输出要求

具体记录：实际姿态、遮挡裁切、可动区域、允许动作幅度、首帧职责与限制。

## 正反示例

可用方案：已坐在窗边的角色轻微抬眼，衣摆仅受微风影响，桌与窗保持稳定。

错误方案：半身肖像被当作腾跃翻滚首帧，模型被要求补出被裁掉的全身与未知空间。
