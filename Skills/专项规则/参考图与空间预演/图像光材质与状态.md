# 图像光材质与状态

## 执行细则

1. 把已定光源、色温、反差、时间状态与主要材质写入实体资料，并区分物体本色、反射、受光和阴影。
2. 同一场景的多图共享光源世界位置；当前机位可以改变受光投影，但不能随机让地板从石材变木材、天气从干燥变雨后。
3. 材质用表面结构、磨损、反射和接触关系描述，服从用户画风。不要以过度反光、塑料皮肤或统一油亮效果代替精细。
4. 生成前落实光源、受光、材料和实体视图的正确状态，后续镜头继承该状态；已有实际图时依据观察描述，不根据提示词推断完成。

## 输出要求

具体记录：主光时间、色温反差、材质表面、接触阴影、稳定状态和当前状态。

## 正反示例

可用方案：雨后石阶的湿润程度在同一场次保持一致，门内暖光与门外冷光的来源明确。

错误方案：每张场景图颜色都类似，但地板、灯具位置和阴影方向完全变了。
