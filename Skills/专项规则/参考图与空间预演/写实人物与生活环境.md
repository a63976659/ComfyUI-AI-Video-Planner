# 写实人物与生活环境

## 执行细则

1. 写实来自身份、场合、材质和环境照明的相互支持，不用超写实、摄影级等标签替代具体内容。
2. 人物保留可见的自然皮肤、衣物结构、身体比例和生活状态，细节服从画幅可读性；不以夸张瑕疵、性化描述或年龄改变换取真实性。
3. 照明与场景时间地点相符，避免无依据的影楼补光和一致光滑表面。用户明确选择风格化时不强制真人写实。
4. 生成前落实脸部结构、四肢、服装、接触、遮挡和身份一致要求；只有实际观察图像才能判断这些结果，单张照片漂亮不能证明资产一致。

## 输出要求

具体记录：身份原貌、生活材质、环境照明、结构检查、用户画风与限制。

## 正反示例

可用方案：刚从雨中回来的角色保留湿外套与门口环境光，脸部不因风格变化被替换成另一人。

错误方案：只写完美无瑕的电影脸，人物像塑料模型，与实际生活环境脱离。
