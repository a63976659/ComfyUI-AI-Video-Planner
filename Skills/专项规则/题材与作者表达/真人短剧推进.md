# 真人短剧推进

## 执行细则

1. 用当前事件和人物欲望建立观看理由，开场信息服务剧情，不默认加入夸张钩子、猎奇标题或假反转。
2. 在有限时长内让行动、反应、关系变化构成推进。减少重复解释，但保真台词不得擅自删改，容量冲突应拆镜或报告。
3. 竖屏机位考虑双人层次、视线、出入口和行动方向；不能把横向多人全景硬裁成只看得到一个人。
4. 真人表演以可执行生活动作承载情绪，留出听懂和选择的时间。高潮与结尾回应人物目标，不套平台广告收尾。

## 输出要求

具体记录：核心欲望、当场冲突、推进节拍、竖屏空间、结尾回应。

## 正反示例

可用方案：母亲准备递出存折又收回，女儿看见这个动作后改变请求方式；推进来自双方选择。

错误方案：所有人物第一秒大喊，接着解释完整背景，最后突然插入关注口号。
