# 题材与视觉表达方向

## 执行细则

1. 依据故事核心、观众感知、人物关系与执行规模确定视觉方向。推荐的是空间、节奏、观察距离和光影方法，不宣称复刻某导演的作品。
2. 给出能直接作用于当前项目的规则，例如固定观察加关键反应切镜、跟随行动揭示环境；不要仅列大师姓名与风格标签。
3. 同时考虑画幅、素材、段时长、角色数量和生成能力。视觉方向不能要求当前没有的摄影、资产或剪辑工具。
4. 方向一旦进入规划成为当前设计依据，后续改写只编译已确定方案。生成前依据当前事件和硬约束落实视觉方向，不因另一套风格更酷而重写已定内容。

## 输出要求

具体记录：视觉方向、观看任务、机位节奏光线原则、适用场次和限制。

## 正反示例

可用方案：悬疑段以受限视角和少量声源揭示组织镜头，关键线索出现后再允许看全空间。

错误方案：只写某导演同款高级电影感，然后每镜套随机推拉。
