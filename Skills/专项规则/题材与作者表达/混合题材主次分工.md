# 混合题材主次分工

## 执行细则

1. 确定主类型负责什么故事任务，副类型在哪些事件、人物或美术环节产生作用；不能只把两套标签并排。
2. 建立世界规则的共存关系：技术、礼制、超自然元素分别如何影响行动与冲突。特殊能力不能临时解决主类型矛盾。
3. 为角色行为、场景材质、道具机制、声音和情绪节奏设统一表达依据；混合不等于每场更换视觉体系。
4. 保真时不得改写原文没有的第二类型。创作允许融合时明确新增依据，并检查结局仍由人物选择与既定规则造成。

## 输出要求

具体记录：主副类型、职责边界、共存规则、统一视觉线索、创作标记。

## 正反示例

可用方案：古代权谋是主线，有限通信装置只改变消息传播方式，不能突然提供无敌武器解决争斗。

错误方案：上一场是写实权谋，下一场无解释变机甲喜剧。
