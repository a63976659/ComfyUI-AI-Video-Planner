# 神话仙侠表达尺度

## 执行细则

1. 先锁定作品的力量层级、价值冲突和代价，不以越大越好决定高潮。能力属于哪个人物、是否已经建立都须可追溯。
2. 区分神话意象、角色能力、环境现象和装饰性效果。意象要关联人物选择或局势，不能用巨型光效代替事件。
3. 确定空间尺度、力量影响范围和资产数量，再设计视觉层次。广阔环境与近身情绪互相补充，不让所有场次都变成远景奇观。
4. 保真模式不新增境界、武器、胜负和法术。素材不足时确定已有依据可支持的具体表现并记录限制，按现有时长与模型能力简化，不留候选设定。

## 输出要求

具体记录：力量尺度、气质、剧情意义、代价、视觉层次与执行边界。

## 正反示例

可用方案：已建立的护阵只能短时阻挡，角色为保护同伴留在阵中，光效展示这个选择的代价。

错误方案：人物危急时突然释放原文没有的大招并改变胜负。
