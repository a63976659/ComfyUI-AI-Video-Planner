# 市井职业与生活痕迹

## 执行细则

1. 从职业日常行动、真实使用工具和工作空间出发设计人物，而不是只写身份名称。工具必须符合已知时代和当前任务。
2. 衣物磨损、手部动作、携带物、工作姿态与生活环境相互对应；生活痕迹用于辨识，不将职业等同于固定性格或阶层偏见。
3. 让角色在剧情中实际使用相关物件或选择，少量清晰细节即可；不要为了展示职业加入不相关工作流程、背景角色和额外时长。
4. 反复出现的工具、衣物与动作习惯登记连续性。原文未写的职业外观、常用工具与动作细节按时代和身份确定并标记规划补全，不留候选；商品数量和专门技艺不能凭空当原文事实，不增加剧情事件。

## 输出要求

具体记录：职业任务、工具用途、衣着痕迹、身体习惯、环境关系。

## 正反示例

可用方案：修伞匠收起未完成的伞骨后去开门，工作桌与手边工具成为身份锚点。

错误方案：任何古代平民都拿同一竹篮，职业只体现在字幕上。
