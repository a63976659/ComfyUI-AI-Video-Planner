# 古装男性身份造型

## 执行细则

1. 把年龄、身份、生活状态和人物目标转换成脸型轮廓、体态、发束冠饰与服装层级；原文外貌优先，不默认同一俊美模板。
2. 人物之间选择少量彼此可区分的稳定锚点，例如肩背轮廓、发型、领口层次和常带物，不依赖颜色微差或同脸换衣。
3. 古装形制必须服从当前时代或架空设定；资料未确定时不用具体历史名词冒充已考证，不将所有男性都写成披发佩剑。
4. 身份图与动作构图分开。换装、受伤、长大等变更建立状态记录，后镜继续引用正确状态，风格化也不能交换角色外貌。

## 输出要求

具体记录：年龄身份、轮廓发型、服装层级、区分锚点、当前状态。

## 正反示例

可用方案：书生偏窄肩、发束整齐并常护住书卷；将军更重的服装层级与旧肩甲承载身份差异。

错误方案：两个男主同脸同发型，仅把衣服从蓝色换成青色。
