# 都市群像辨识与关系

## 执行细则

1. 建立每位角色的社会位置、当场目标、关系与已知外貌；按名字和别名做身份对照，不让同名或相近名字自动合并。
2. 为每人设置不同的轮廓、发型、穿着层级、常带物和行动抓手，优先两三个可见锚点，不堆几十项难以执行的差异。
3. 区分说话与回应方式：直接请求、回避、确认、试探等来自关系和目标，而非把职业或性别变成刻板口音。保真台词仍不得改字。
4. 群体画面说明每人位置、视线、正在做的动作及出画去向；镜头选择服务当前事件，不让背景人物抢主行动。

## 输出要求

具体记录：身份表、别名、锚点、说话与反应方式、关系、群体位置。

## 正反示例

可用方案：三位室友分别整理文件、收行李和守着门口，讨论中的不同目标通过行动保持可辨。

错误方案：五个角色都站直微笑，说同样的完整道理，只靠姓名标签识别。
