# 战斗人物能力边界

## 执行细则

1. 根据原文建立训练背景、身体状态、武器或能力来源及使用限制。角色能做什么与不能做什么必须同时明确。
2. 身体习惯服务身份与剧情，但只写可见准备、移动、持物和反应，不把职业名称当作拥有所有招式和武器的理由。
3. 受伤、疲劳、负重、装备与环境改变动作选择和时长。当前状态不能在下一镜自动恢复，特殊能力不能凭空扩展。
4. 保真范围内不新增没有原文依据的战斗技艺、武器、弱点和胜负。创作范围及设定补全遵守共用要求。

## 输出要求

具体记录：能力来源、装备状态、身体限制、惯常动作、禁止新增项。

## 正反示例

可用方案：受伤护卫按已知负重限制退到门边保护同伴，镜头不让他突然改用原文没有的远程能力。

错误方案：人人同时会剑术、枪械、飞行与治疗，能力只随镜头需要变化。
