# 现代男性生活造型

## 执行细则

1. 核对年龄、职业、生活环境与当天场合，再确定服装、体态、发型和携带物。职业不是固定穿衣模板，原文要求优先。
2. 用可见的生活状态建立辨识度，例如衣物是否打理、惯常携带物与身体节奏；不能只写帅气、成功或疲惫。
3. 区分稳定身份与临时表演：犹豫不是永远驼背，愤怒不是每镜攥拳。造型锚点保持稳定，行为随事件改变。
4. 现代空间与人物消费、出行和工作条件相符。不要根据性别、职业或阶层强行赋予道德特征，未指定细节直接确定并标记创作补充。

## 输出要求

具体记录：年龄职业、生活状态、外观锚点、场合服装、动作习惯。

## 正反示例

可用方案：夜班护士的口袋物品、未换下的工装和放松肩膀的动作体现刚下班，身份不靠外貌评价。

错误方案：所有现代男性都穿黑西装、背头、冷脸，换名字没有区别。
