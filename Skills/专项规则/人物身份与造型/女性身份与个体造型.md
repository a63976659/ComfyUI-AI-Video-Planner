# 女性身份与个体造型

## 执行细则

1. 先明确年龄、职业身份、生活处境与人物目标，再决定发型、妆面、服装和身体状态。漂亮不是角色设计的完整答案。
2. 稳定锚点优先来自原文或用户素材，衣着服从行动与场合。不同人物不能共享同脸，仅靠妆色或性化描述区分。
3. 表演和外观分开：脆弱、坚强、权力或迟疑都通过当前行动表达，不预设女性只能温柔、哭泣或被动。
4. 换装、妆面变化、伤势和时间跨度需要状态记录；保真时不凭美化改变年龄、身份、身体特征或剧情责任。

## 输出要求

具体记录：身份目标、外观依据、发型妆面、行动服装、区分锚点与变化状态。

## 正反示例

可用方案：年长店主用实用围裙与记账习惯建立身份；年轻访客用原文明确的短发和旧背包保持辨识。

错误方案：所有女性都写成长发精致妆容和纤细身材，没有生活状态与人物选择。
