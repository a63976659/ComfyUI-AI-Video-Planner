# 奇观尺度与视觉层级

## 执行细则

1. 高潮尺度首先回应人物目标、代价与局势，不自动扩大到毁城、灭世或增加群体伤亡。原文规定的结果不可改变。
2. 通过近处人物、关键地标与远处环境建立可读尺度，观众应知道力量从哪里来、影响哪里、与人物有什么关系。
3. 节奏可从克制准备到必要揭示再落在结果与反应；不是每镜都必须最大景别、最大光效和最多运镜。
4. 控制主体、特效与环境的层级和同时动作数，避免巨量细节使身份、空间和因果丢失。能力不足时保留意义并简化规模表达。

## 输出要求

具体记录：剧情高潮任务、尺度锚点、力量范围、视觉层级、节奏与原文结果。

## 正反示例

可用方案：远景借人物与既定山门对比展示护阵尺度，随后回到角色选择和消耗，结果不超原文。

错误方案：用一屏光效遮住人物和目标，并凭空毁掉原文完好的城镇。
