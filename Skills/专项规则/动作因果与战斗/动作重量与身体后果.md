# 动作重量与身体后果

## 执行细则

1. 用支撑、重心转移、动量变化和接触后的身体状态描述动作，不以轻飘飘的招式名称代替可见过程。
2. 受力与反应保持方向关系，防守、闪避和未命中也有身体调整；不为了显得强而让物体或人物无原因飞出。
3. 伤势、疲劳、持物和地面条件延续到后续行动。受伤、血腥、残疾与致命后果按已确定设定呈现，保持创作权限边界。
4. 准备、主动作、恢复和必要反应需要时间；复杂连招拆成清晰节拍，不能通过慢动作形容词掩盖执行段容量不足。

## 输出要求

具体记录：支撑重心、运动接触、反应方向、恢复状态、连续限制与估时。

## 正反示例

可用方案：格挡后角色调整支撑脚并退回稳定位置，下一镜沿用他仍握住道具的状态。

错误方案：人物无接触就突然倒飞，下一镜却恢复站直且原物件消失。
