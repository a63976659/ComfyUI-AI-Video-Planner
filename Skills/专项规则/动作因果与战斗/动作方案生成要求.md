# 动作方案生成要求

## 执行细则

1. 逐链核对目标、距离、方向、支撑、接触、受力、结果与恢复，不仅检查招式名称或镜头数量。
2. 对照原文或已确定的授权创作设定安排胜负、伤势、武器、能力和破坏事件；不因视觉效果临时越过创作边界。
3. 检查相邻镜头是否重复发起、跳过关键应对、反向受力或瞬移；换场和跳时有明确依据时不强求连续姿态。
4. 生成前确定各行动节点与镜头的正确衔接，保留原定结果；依据实际观察范围组织动作，不宣称已验证未观察的完整运动。

## 输出要求

具体记录：动作节点、证据、时长与状态安排、原文依据、当前任务对象与证据范围。

## 正反示例

可用方案：上一镜完成挥拳接触，下一镜直接从接触后的恢复继续，保留原定结果，不重复从初始姿态挥拳。

错误方案：只因动作词多、时长够就判通过，忽略没有接触与应对。
