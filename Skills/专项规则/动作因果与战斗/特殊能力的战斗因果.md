# 特殊能力的战斗因果

## 执行细则

1. 以已建立的触发、作用对象、范围、持续与代价决定能力介入，不把特效作为打断物理动作逻辑的理由。
2. 释放、对方应对、能力接触环境或目标、结果与恢复须有可见关联。反制和免疫需要故事依据，不能临时增加。
3. 能力改变位置、速度、遮挡或环境后，普通动作与持物状态也必须更新。力量影响外的物体不要无原因爆炸或漂浮。
4. 区分能力规则与生成模型能可靠表现的动作。过多同时效果优先分节拍或简化视觉，保持原胜负和情节因果。

## 输出要求

具体记录：触发与作用对象、范围时间、应对依据、物理结果、代价与状态。

## 正反示例

可用方案：已知短时屏障拦住通道，角色必须绕行，屏障结束后环境和人物位置继续接上。

错误方案：释放一道光后双方位置与持物全部重置，反制凭空出现。
