# 地形与群体局势

## 执行细则

1. 用可达区域、障碍、高低差、出口与遮挡建立战场拓扑，再说明当前双方想控制哪个位置或通路。
2. 群体行动分成少量有职责的小组，明确谁牵制、谁移动、谁保护或撤离；不让背景角色随机绕主角跑动。
3. 环境参与局势变化必须有行动原因和持续后果。地形不是突然出现的救命工具，已破坏或封堵的路线不能下一镜恢复。
4. 摄影机优先展现当前局势与方向，聚焦关键行动链。大范围结果可以通过有限地标与反应交代，不强迫短段同时生成所有群体细节。

## 输出要求

具体记录：区域路线、角色组职责、控制目标、环境变化、局势结果、观看任务。

## 正反示例

可用方案：退路被既定障碍限制后，人物改走已经建立的侧通道，群体位置因此发生可追踪变化。

错误方案：空地上群体互挥动作，没有目标、区域和环境结果。
