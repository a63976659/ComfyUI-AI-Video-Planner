# 终结动作分节拍编排

## 执行细则

1. 对照已建立能力拆出准备、聚集、释放、遭遇抵抗与结果，但按实际事件选用节点，不把五段链机械变成固定五镜。
2. 每段明确人物行动、能力变化、观察对象与环境结果；聚能不能只是无限膨胀光球，释放与接触需有方向和对象。
3. 保留角色选择、能力代价、对方应对与已确定胜负。伤势、破坏、能力升级和反制须有原文或已确定的授权创作设定依据。
4. 为每个必要节点估时并分配执行段，起止状态交接清楚。超预算简化无关视觉，不跳过决定局势的关键因果。

## 输出要求

具体记录：准备条件、节点顺序、力量方向、应对与结果、代价、状态及时间。

## 正反示例

可用方案：护阵由角色启动，短时承受已知冲击后结束，下一镜保留消耗后的身体状态与同伴去向。

错误方案：只写释放灭世大招，一秒内聚能爆炸结束，原有失败结局被改写。
