# 属性效果与环境响应

## 执行细则

1. 根据故事内属性机制选择运动、材料、光线和持续，不只更换颜色。现实规律可供视觉理解，但不得擅自替作者新增能力规则。
2. 明确触发点、传播或作用方向、接触目标、影响范围和停止条件；多个属性同时出现时说明它们的关系，不让特效互相吞掉主行动。
3. 能力照亮、遮挡、冻结、吹动或改变环境时，受影响的物件与人物必须可追踪，影响外区域不无理由变化。
4. 对照原文限制、代价与胜负。模型难以完成多层特效时减少并发，拆出可读节点，不能将不可执行效果当作已生成。

## 输出要求

具体记录：属性机制、运动材质、光影方向、接触与环境反馈、结束条件、限制。

## 正反示例

可用方案：风的表现围绕既定作用范围移动轻物和衣物，关键目标与人物位置仍清楚可见。

错误方案：同一发光爆炸换红蓝紫就算三种属性，环境结果每镜自动复原。
