# 攻防事件完整链

## 执行细则

1. 明确各方当场目标、距离、朝向和空间条件，再写发起、应对、接触或未命中、受力与结果，避免各自摆动作没有关系。
2. 防守、闪避、格挡和退避都需要可见结果；未接触不能出现莫名击退，接触不能自动意味着胜负改变。
3. 记录支撑、重心、持物与环境状态，动作后更新位置和恢复状态。伤势、能力、武器与结局按已确定故事设定延续。
4. 单镜围绕有限主动作，复杂连锁先拆分；观看角度须让攻防关系可读，估时含准备和必要反应，不机械套固定秒数。

## 输出要求

具体记录：目标距离、发起应对、接触受力、结果恢复、空间状态与时长。

## 正反示例

可用方案：对方推来时主角抬臂挡住，随接触调整支撑并退一步，镜头保持双方方向可读。

错误方案：两人连续挥舞，既无接触也无闪避，最后突然宣布胜负。
