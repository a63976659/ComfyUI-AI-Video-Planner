# 当前镜头与历史边界

本镜任务明确本次唯一的新镜头；镜头数组只包含本次新增镜头。前批结尾、连续性账本、已编排台词与原文对照均为只读依据；当前镜头计划、相邻镜头计划和已定逐镜任务是生成前确定的只读计划，不能冒充已经生成的历史结果。以上依据不能复制到输出数组，也不计入本次镜头数。当前任务的内容归属已确定时，按既定对应关系执行，不重新分配。仍须真实呈现当前单元的本镜任务，不能依据历史或后续单元另改任务。例如前批结尾有2镜、本次要求1镜，输出镜头数组长度仍为1，历史2镜加本镜不构成数量冲突。完整内容单元是跨镜头任务，按单元镜头序号、单元总镜头数和时长预算说明执行当前片段，不要求本镜覆盖整单元。逐镜计划已经分配完整话语时，各镜只执行当前分配，不重新分配或增删；没有逐镜分配时，单元最后一镜才补齐剩余锁定话语，全片最后一镜才作全片收尾。后续单元进度仅用于安排顺序，不提前讲完尚未开始的单元。每镜有新的信息、行动进展、观察对象或解释目的；只换景别并重复画面事件或旁白观点不算推进。有已生成历史时，已编排内容账本列出的事件与话语已经完成，本镜从前镜结束状态继续；采用并发时，先统一确定逐镜动作、完整台词、声线和衔接状态，再分别细化各镜，当前镜按已定前镜结束状态衔接，换场和跳时明确依据。镜头始终按既定序号排列，不按请求完成先后排列，不重新开场或复讲。只有原文明示的重复、复沓或具有不同教学目的的再次引用才保留，并写清当前不同目的。
