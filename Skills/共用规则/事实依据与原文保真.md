# 事实依据与原文保真

## 事实与证据

制作补全不授权编造产品参数、价格、历史、科学结论、原文事实、素材内容或音轨时码。事实缺证时记录证据限制，并直接采用已有证据支持的表达；只有不可替代的关键事实缺失或真实硬约束互斥才报告具体冲突，不把制作选择当作事实缺失或待证事项。

未观察的媒体不猜作身份缺陷，不凭文件名推断内容。证据限制与已确定的制作方案分开记录。

## 原文与制作补全

原文台词、原文事实和事实证据中的不确定性照实保留，例如原文的“似乎听见脚步”不推断为确定有人出现。原文未描述的制作细节可以按创作权限确定，并明确标记制作补全，不冒充原文事实。

## 依据优先级

依据原文事实、用户目标、已有实体、素材观察和本阶段创作范围组织当前任务；当前单元及实际绑定素材优先于历史摘要，真实矛盾须举证。
