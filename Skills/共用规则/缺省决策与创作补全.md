# 缺省决策与创作补全

依据当前全部规则、原文、素材和已定声音身份组织唯一完整方案；能按规则直接决定的事项直接决定，不交付相互矛盾的描述。

生成前从完整需求确定共用创作意图：表达目标、必须保留的内容、禁止改动的范围、素材职责、创作权限和已定制作安排。明确要求保留逐字依据，各阶段沿用同一份创作意图，当前任务只细化自己的承载内容，不擅自重新解释或扩大权限。素材正文的事实仍在各自阶段完整读取，创作意图不能代替正文。

用户明确要求优先于默认审美、示例和缺省制作选择；实际执行能力、事实依据和当前输出契约仍须遵守。默认规则与明确要求不一致时直接采用明确要求，不作为两项用户硬约束报告冲突。未指定的受众、风格、机位、节奏、造型和普通制作安排由规划师直接确定，不要求用户理解内部规则或代为协调。

创作权限依据用户需求和用户明确选择的处理模式确定。用户要求创作、扩写剧情或建立虚构设定，或明确选择创作补全时，按其要求确定创作范围，无须出现“授权创作”字样。用户仅提供创意并要求发展内容时，可自动识别为创作补全；已有成型的小说、剧本、事实文案或分镜默认保真，“改编”本身不授予任意新增剧情的权限。规划过程只能识别已有创作意图，不得因时长不足、情节不够丰富或原文未写明而自行扩大创作范围。

所有类型统一遵守：在已确定的创作范围内，用户未提到的创作与制作要求，由规划师依据内容直接确定一个具体、可执行且前后一致的方案，标为规划确定或创作补充。

内容规划、全剧分集、人物场景、声音、镜头均不得把这些决定留为自动、未知、待定、候选、待用户确认，不得用可能、也许、可以考虑、建议采用、视情况、按需选择、A或B等模糊或不确定描述代替决定；不列备选方案让用户再选。

具体确定表达体裁、受众、基调、视觉风格、人物造型、场景、动作、机位、节奏、声音及实际需要的制作安排；无须使用的元素明确不使用，不为补全而增加无关剧情。独立策划未给账号定位时，从当前行业和观看价值确定，不反问用户选风格。

保真范围或未授权新增的范围，不补写原文没有的人物经历、关系、独立事件、胜负、伤情、武器、战斗技艺、弱点、能力、破坏和结局。已确定的创作范围允许发展剧情或建立虚构设定时，在该范围内直接确定具体设定、因果及代价并标记创作补充，不输出候选，不改写受保护的人物事实、锁定话语或既定结果。生成前确定后的设定保持一致，不在后续编译中临时增加或改写。

原著未写明但制作必需的造型、场景陈设、光线、机位和表演细节，按时代、身份、环境、既定风格与已有状态直接确定唯一方案并标记规划补全；最终制作字段不留未知、候选或待确认。不得借此扩写剧情、新增独立事件、角色经历、关系、因果、结局或锁定话语。用户明确禁止补充的范围仍遵守原要求。
