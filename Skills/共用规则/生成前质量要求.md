# 生成前质量要求

- 输出前落实当前任务的完整内容、动作与连续性要求，只提交最终结果，不输出推理草稿或未经实际验证的通过结论。
- 生成前对照完整当前原文、用户硬约束和锁定话语，落实结构、来源、覆盖、人物、表演、素材与执行范围。新增内容须有创作权限及补充标记，不靠改变结局或删必留内容消除问题。
- 逐项落实当前专项的执行细则与输出要点，直接写清主体、行动、位置、结果及可观察变化，不以形容词代替实际安排。衔接相邻镜头的真实起止状态，统一人物位置、持物、视线、轴线与动作方向；主体动作、画面和运镜采用同一可执行安排，不凭尚未发生的动作开始下一镜，也不把模型能力之外的效果写成已实现。
- 媒体未实际观察时只判断计划一致性，不声称已观看成片、听过音轨、验证完整运动或完成真实质量评估。只有不可替代的事实或素材缺失、真实硬约束互斥才说明具体冲突；自己的字段错误、未落实的制作决定不能转成用户资料缺失。
