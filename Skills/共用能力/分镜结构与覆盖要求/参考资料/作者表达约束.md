# 作者表达约束

## 执行细则

1. 从用户明示的色彩、节奏、表达尺度、禁令和参考用途建立项目规则；区分必须遵守、可选偏好与模型建议，显式要求优先。
2. 把抽象要求变成可观察约束，例如克制表现为有限动作与必要停顿，而不是删掉冲突；悲伤不自动等于下雨、慢镜和哭泣。
3. 每阶段沿用相同约束并记录变更依据。参考只借指定的语言方法，不带入外部作品的剧情、对白、角色或未经许可的素材。
4. 规则冲突时保留来源和矛盾，自动选择不违反硬约束的方案；没有可行交集就明确失败，不能偷偷改变目标或要求用户中途逐项确认。

## 输出要求

具体记录：硬约束、审美偏好、参考职责、表达尺度、来源与冲突。

## 正反示例

可用方案：用户要求无对白且克制：用收起旧物与未完成的拥抱表现关系，不另加煽情旁白。

错误方案：把用户的安静家庭故事改成开场反转、痛哭与广告式收尾。
