# 场次目标与变化

## 执行细则

1. 用人物在本场要获得什么、遇到什么阻力、采取什么行动和最终变化定义场次任务；无人物内容改为展示目标与观众信息变化。
2. 区分剧情任务、关系任务和可见任务。不能只写两人聊天、情绪升级或场景漂亮，需要明确这场结束后什么不同。
3. 保真时以原文事件为依据，不能为了提高冲突加入秘密、误会、胜负或新的结局。解释性信息尽量有可见对应，但不更改锁定台词。
4. 核对场次与前后因果连接。看似安静的场次也可能承担关系、准备和反应，不因没有大动作就自动删除。

## 输出要求

具体记录：目标阻力、行动选择、开始结束变化、视觉任务、前后因果。

## 正反示例

可用方案：主角试图归还钥匙，却发现对方不愿接；场次结果是关系没有恢复，而非泛泛的伤感。

错误方案：只写两人深情对话，没有目标、动作或结束后的改变。
