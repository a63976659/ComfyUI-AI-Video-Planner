# 场次节拍与时长预算

## 执行细则

1. 把一场的必要事件、口语、动作、独立停顿和关系变化列明，按共用时长与容量规则估时。
2. 场次预算必须能够解释开场定位、事件推进与结果，不平均分配所有场。静默与反应可以有时间，不以字数密度填满整个场次。
3. 新增动作或台词后重新比较场次预算与总目标，说明差额来自哪个节拍。锁定文本装不下时拆镜、延长自动时长或明确冲突，不私自加速和删句。
4. 实际音轨与测得动作时间优先于估算；未有音轨不得给词级对齐或精确发音承诺。执行段边界由当前模型能力决定。

## 输出要求

具体记录：事件节拍、并行与顺序关系、口语与留白估算、场次预算及冲突。

可用方案见[场次估时示例](../../../共用规则/时长与容量.md#场次估时示例)。

错误方案：每场都分成同样长度，40字台词和长动作一起硬塞最短段。
