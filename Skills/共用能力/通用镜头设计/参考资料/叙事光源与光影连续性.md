# 叙事光源与光影连续性

## 执行细则

1. 先确定时间、地点与可成立的主光来源，再决定方向、亮暗关系和色温；月光、窗光与室内灯不能随切镜无理由互换。
2. 区分光源所在的世界位置与当前画面受光方向。摄影机绕到另一侧会改变受光投影，但物理光源仍应位于同一窗、灯或火源。
3. 用光影响能见度、空间层次和角色选择；不能把黑暗写成看不清必须展示的关键事件。补光和轮廓光应服从画风，不凭空出现舞台灯。
4. 火光、闪电和法术等瞬态光记录发生时机、持续范围、受影响物体和恢复状态。没有明确触发时维持稳定，不逐镜随意改变曝光与颜色。

## 输出要求

具体记录：主光来源、世界方向、明暗与色温、主体受光、变化触发和证据限制。

## 正反示例

可用方案：人物先站在窗边冷光中，主动走近桌灯后脸部转为暖光；窗与灯在后镜保持原位。

错误方案：同一房间每切一镜都换太阳方向，关键道具却始终被暗部遮住。
