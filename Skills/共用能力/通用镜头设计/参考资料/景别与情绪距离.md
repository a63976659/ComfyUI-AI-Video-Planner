# 景别与情绪距离

## 执行细则

1. 先判断观众此刻需要知道空间、行动、关系还是细微反应。远景交代位置，中景保留身体行动，近景聚焦倾听与表情，特写只突出有叙事意义的细节。
2. 为景别变化找到信息或情绪依据；切近不是自动升级情绪，同景别持续也可能表达压迫或克制。动作需要看清手脚与接触时，不能为了情绪把关键行动裁掉。
3. 核对前后镜的信息增量：人物已经被识别后无需重复建立；新场景或人物入场先给必要定位，再收近，不把全场机械写成一串近景。
4. 景别变化同时检查背景地标、视线和动作方向。复杂多角色镜头优先保留关系可读性，单个执行段不要承诺多次精确景别切换。

## 输出要求

具体记录：观察目标、景别、保留在画内的行动、与前镜信息差、选择理由。

## 正反示例

可用方案：门口中景同时看见归来的姐姐与听到动静的弟弟；收到回应后切弟弟近景，看他放下杯子的迟疑。

错误方案：每句对白固定切一次特写；打斗中只看脸而看不见接触和退步。
