# 构图与人物关系

## 执行细则

1. 把人物的目标、注意对象和空间距离先转成相对位置，再选择中心、三分、对称、前后景或留白；不把构图术语本身当成戏剧内容。
2. 前景遮挡必须来自真实物件并留出行动视线；被压在画边可以表达关系，但不能遮掉关键动作或误让人物消失。没有人物时将方法用于产品与环境层次。
3. 保持世界位置与画面投影区分。变换机位可以交换屏幕左右，须说明观察方向和地标；不能机械锁左锁右却让实际机位矛盾。
4. 按已定画幅检查头顶、视线、移动方向和字幕安全区。人物将向一侧行动时预留空间；准确文字和品牌标识须使用真实素材或后期层。

## 输出要求

具体记录：主体层级、前中后景、相对位置、视线、留白用途、画幅限制。

## 正反示例

可用方案：掌柜在柜台后占较高位置，求助者站门口前景侧边；柜台距离成为双方关系的可见障碍。

错误方案：所有人物居中排队，人物关系只靠画外形容词解释。
