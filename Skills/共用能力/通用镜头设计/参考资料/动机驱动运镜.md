# 动机驱动运镜

## 执行细则

1. 先问运动能让观众看见什么新信息：跟随主体、揭示环境、改变距离、展现关系或转移注意。不能只写镜头高级、炫酷或持续运动。
2. 明确起始机位、跟随对象、运动方向、路径、速度变化与停止位置。推拉改变距离，摇镜转移视线，横移揭示遮挡；选择与空间条件匹配的一种主运动。
3. 运动与主体动作保持可读关系；跟拍不等于人和摄影机各走各的。固定镜头可以由人物入画、景深或光线变化承载信息，不因静止判错。
4. 检查路径是否穿墙、撞桌或绕过未知空间。复合运动分节拍记录并与段时长匹配；能力不足简化运动，不擅自增加新镜头或时间。

## 输出要求

具体记录：方式、动机、起点、对象、路径、速度、终点及执行限制。

## 正反示例

可用方案：摄影机沿走廊侧向跟随主角，在他停到门前时一起停下，让门牌进入画面。

错误方案：人物原地谈话，镜头每秒推拉摇移，只因需要电影感。
