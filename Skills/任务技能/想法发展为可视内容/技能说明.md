# 想法发展为可视内容

## 使用范围
输入只有主题、想法或不足以形成镜头的需求时启用；用户已给出完整剧本或分镜时不默认扩写。

## 内容发展
- 根据目标生成一条适合时长的内容线。剧情发展可见行动；讲解组织问题与说明；广告围绕用户提供的产品事实，不强加三幕结构。
- 把抽象情绪变为人物可观察的行为、环境变化或具体展示。每单元写清“开始状态、发生什么、观众得到什么”。
- 尊重 必须保留项 与禁令；新增人物、道具、动作标为 创作补充，不伪称用户已经提供。
- 短输入直接确定可见事件与镜头安排，不先写长篇小说再切镜头。
- 未给出的产品数据、历史事实或专业结论不借创作自由填造，记录证据限制并采用已有证据支持的表达；只有不可替代的关键事实缺失才报告冲突，不把资料不足变成待定制作方案。

## 输出
承载具体事件或信息、观看目标、必要创作补全、真实依据及必须保留内容；镜头直接表达对应事件，不因篇幅丢失要求。

## 最小案例
“机器人第一次看见雪”：发现窗外下雪 → 伸手接雪 → 看见雪融化 → 安静站在雪中。规划时确定具体拍法与数量；这是创作补充，不能称原文场次。
