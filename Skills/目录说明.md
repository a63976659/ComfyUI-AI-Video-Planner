# 读取入口

- [技能目录](技能目录.json)：主任务、共用能力与具备独立入口的专项。
- [专项目录](专项目录.json)：统一维护共用能力参考细则的适用阶段，以及专项的触发条件、适用阶段和条件参考；执行细则与输出信息仅维护在对应正文。
- [共用目录](共用规则/共用目录.json)：规则依赖与共用正文。

先确定当前任务及输出范围，再读取对应规则、主任务、阶段能力、适用的共用细则、命中专项和必需详细参考。资料完整性与请求内共用要求见[生成前质量要求](共用规则/生成前质量要求.md)。

任务技能处理输入，共用能力提供通用制作方法及参考细则，专项规则保留按内容条件启用的独有能力与执行细则。
