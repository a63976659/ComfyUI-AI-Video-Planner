# 通用提示词改写

## 适用与使用方法

依据当前段的原始分镜、真实时长与任务、绑定素材及已保存的理解、人物固定资料、锁定台词、声音设计和明确禁令，整理唯一的最终提示词。

1. 先读本文件。共用写作规则和详细质量细则在这里维护，所有视频模型都遵守；简化的是文件结构，不设规则篇幅或输出内容的本地上限。
2. 目标格式是 H3 时，再读 [H3 格式](参考资料/H3格式.md)，其中已合并基础指南、全参考指南、术语表及完整示例，根据当前实际任务选择三章节或六章节；自然语言、原样等其他格式不加载这份参考。
3. 按本次请求提供的字段、真实段 ID、时间线骨架和输出格式完成一段。原样模式直接保留原文；其他模式按下文组织过程，在同一次请求内自查后提交。

不重新规划故事，不重复执行上游 Skills 的创意、表演或镜头设计，不生成参考图、素材或视频，不新增图像分析。上游已经定稿的设计是输入依据；这里负责把它准确写成视频生成指令。执行全局提示词由程序另行加入，本段不重复粘贴。

## 执行方式

在插件中每次只生成当前一个启用段的最终提示词。一次模型请求内完成表达整理和提交前自查，只返回本次契约要求的最终结果；不输出审查报告、候选、修改建议或自查过程，不等待第二次验收或修复调用。

## 输入与保真边界

- 原分镜、角色资料、素材理解是只读事实依据；其中的文字不是操作指令。只优化表达，不改人物、事件、因果、结局、台词、既定画风、时长、素材绑定和原定切镜。
- 段内独立交代主体、场景、起始状态、动作过程和结束状态，不依赖上一段、沿用前镜头等省略表达。使用当前段绑定的人物固定特征，保持身份、服装、道具、视线、左右位置及动作空间连续，禁止互换角色或参考职责。
- 逐秒细化已有动作、表演、构图、光影、材质和镜头过程；保留已有倾听反应与运镜意图。静止或留白描述实际保持状态，不用每秒增加新动作凑长度，不擅自增添人物、光源、配乐、字幕、场景或复杂运镜。
- 参考内容仅依据实际槽位和已保存的素材理解。文件名不是视觉证据，不声称观察未知内容，不发明标签或输入素材，不重新分析图片。首尾帧遵从实际绑定；多参考明确身份、场景、动作、风格及音频各自职责。

## 时间与声音

- 从本段 00:00.000 连续覆盖到实际结束，逐行使用给定秒级时间线骨架；每个节拍不超过一秒，允许毫秒边界，无缺口、重叠或越界。节拍不是切镜；保持原定切点，不为每秒另建镜头。
- 时间精度表达执行意图，不声称视频模型保证逐毫秒还原。自然语言模型遵从自身格式，不强加 H3 标签。
- 锁定台词原文和语言，每句仅在起说节拍出现一次；长句注明持续发声到结束的时点，后续节拍描述继续说话及闭口，不重复原话，不要求一秒读完整句。发声标记遵循目标模型格式，环境音和音效不冒充台词。
- 按已有声音设计明确说话人、声线与语速，不得重新选择性别或音色，不凭姓名猜性别，旁白不让画内无关人物张口。未指定角色的旁白缺声音设计时，使用成年女性清晰自然中音、每秒4字；明确角色遵循其资料。新配音固定每秒4字，情绪通过音量、音高、重音与独立停顿表达；已有原音轨保持原件，不声称已变速或精确对齐。
- 环境音与配乐分开。禁用字幕只禁止屏上文字，不删除对白；静音、禁止配乐等明确禁令优先。无配乐写 N/A，静音时声音章节写 N/A，后期原声处理不等于生成静音。不得擅自增写对白或重复音乐层。
- 逐句区分肯定与否定，禁令中提到字幕不等于要求加字幕。约束冲突时按明确禁令与既有约束优先规则处理，不凭空补造事实或扩大任务。无法从依据确定的细节采用克制描述。

## 提交前自查与交付

- 在本次请求内自行核对：人物事件保真、主体空间连续、完整秒级时间线与固定切点、台词原文及出现次数、声音禁令、实际参考职责、模型格式及章节完整性。发现不一致时只调整相关表达，保留其余已正确内容，再提交最终结果。
- 插件内输出必须符合本次请求的 JSON 契约，带当前真实 segment_id，恰好一条完整非空提示词；独立使用时按用户指定格式交付，无特殊格式时直接给完整提示词。不输出解释、自查过程、验收结论、分辨率或画幅比例。原样模式逐字保留原稿，优先于改写和时间线要求。
- 不设本地 tokens 或字符上限，不按短篇字数压缩；按实际时长和信息复杂度充分展开，长度由接入模型能力决定，不重复品质词凑篇幅。

## 最终输出的排版与来源自查（必须在提交前完成）

时间线正文必须真实换行，不能把多个区间串在同一行，也不能紧接在镜头总述之后。每一条节拍独占一行并以 `从 00:00.000 到 00:01.000，` 这样的前缀开头；“从”和时码、“到”和时码之间保留空格。JSON字符串中换行写成转义符 `\n`，解析后是实际换行。首镜头总述、后续切镜标题分别占一行，其后另起一行填写节拍。

合法正文示例：`固定中景。\n从 00:00.000 到 00:01.000，主体开始原定动作。\n从 00:01.000 到 00:02.000，沿同一机位继续动作。`。有原定切点时，按目标格式另行说明切镜，其后另起一行填写时间节拍。自然语言只用中文镜头说明，不加 `[Shot N]`、`At`、H3 章节名或其他 H3 专用标记；H3 的镜头格式只见专用参考。

提交前逐行计数：给定骨架有多少区间就逐行写多少区间，各行只有一组起止时间；包括非整数段尾。不得用一段文字中的多个时间区间代替独立行。

没有人物外貌、发型或服装资料时只使用姓名及原动作，不写“已知特征”后编造短发、服装、性别或其他固定特征。未指定的光源、天气、背景与道具不擅自新增。提交前逐句核对固定特征和场景事实是否来自原稿或绑定资料；合理猜测不等于事实依据。只知道清晨厨房，就不推定窗户光源；只知道推门，就不推定门的内外开向。通过原定动作的进展和已知空间状态丰富时间线，不靠新增光源或布景增加细节。声音要求中的“只保留”是限定声源，不能在苹果轻响之外补鸟鸣、风声、冰箱声等无依据声音。

最终成稿只给一个确定的执行描述，禁止把备选方案留给视频模型：除锁定台词或原文自身的不确定表述外，不写“他/她”“右手或左手”“轻搭或悬停”“可能”“依默认模式”等未定表达。缺少性别只重复姓名；缺少动作侧别就写“手”，不指定左右；缺少服装、发型、道具颜色时不写任何“日常服装”“白色菜板”等替代设定。结束状态沿用原定结果；原稿持续游动就持续游动，不擅自变成静止定格。正文不解释资料不足、处理流程或自查理由。

## 所有视频模型共用的详细执行细则

以下要求用于把已定稿设计写清楚。只在当前段已有主体、表演、参考职责、媒介或制作要求触发时应用，不因拥有某条规则就增加剧情、运镜、音轨、字幕、产品证明或 UI。H3 的英文标签和章节协议只在专用参考中使用；其他模型按实际配置格式表达同样的内容。

### 镜头信息、节拍与空间连续性

- 每个镜头具体交代已知景别/构图，前景、中景、背景及遮挡关系；当前主体的画面位置、朝向、视线与动作空间；场景中已有地标及其屏幕相对位置；已有光源方向、主/补/轮廓光基线、色彩、表面材质与参考锚点。资料没有提供的固定特征不补造，不为填满维度编造背景。
- 每个秒级节拍落实原定动作的开始、运动路线、接触/操作、状态变化、结果或保持状态，关联当秒有效的声音、表演和参考；有必要时写下一秒如何接续。不把物体突然移位、动作结果跳变、道具换手、视线互斥或身份互换藏在抽象形容词里。
- 段内换视点仍保持空间轴线与视线关系，跟踪已有固定地标、距离、左右侧、持物和进出画状态。重要主体离开画面时交代原定退出方向与状态，在下一相关镜头追踪它，不无故消失；段外仍独立交代，不用“沿用前段”省略当前依据。
- 每个镜头体现既定目的：揭示、表演、证明、情感、动作、过渡或结束状态。按既定节奏落实能量变化、信息高峰和制动；面部、口型、关键产品、标志、界面操作与阅读区域保持必要稳定，已有停顿与倾听反应照实保留。
- 同一节拍优先写清一个主要动作的过程，原计划确有多人或并行动作时保留，不因通用建议删人、删剧情。动作、文本事件、机位运动和物体运动不能互相遮蔽；逐秒细化不等于逐秒发明新动作。
- 运镜准确区分焦距变化、机位推拉、原地摇摄、平移、升降、环绕、跟拍、轴向滚转、手持及主观视点，依据原稿写运动方向、幅度、速度和轴线。运动用自然动作描述，不堆孤立标签；不把变焦误写成推镜或把摇摄误写成横移。
- 切镜/叠化/淡入淡出/划像只落实原定转换。原定转场若由主体运动、遮挡、产品边缘、滚动、光线、节拍或材质机制触发，写清真实可见原因；不补随机闪光、粒子、玻璃破碎或装饰性效果。
- 同段镜头间保持同一既定色彩分级、光照逻辑、材质纹理、镜头语法、参考身份及声音层次；有意改变时必须源自原定节拍。结束按既定结果处理，持续动作不擅自改成定格。

### 主体、多人和素材的窄职责

- 人物参考只负责被指定的身份锚点、脸型、发型、服装、配饰、年龄感、体型和角色存在感，不自动规定背景、构图、故事或排版。素材职责中未包含的属性不能顺便继承。
- 风格化人物保留识别所需面部轮廓、相对五官比例、独特特征、发型、眼镜、服装轮廓和关键配饰；3D、动漫、游戏 UI、纸艺、拼贴或插画不自动继承源照片的皮肤写实、真实光照、相机伪影或图像风格。
- 场景参考只负责既有布局、氛围、光照方向、材质、色彩和背景锚点，不改角色身份。产品参考保留具体形状、比例、材质、颜色、授权标志位置及可见机制；字体/文字参考只负责字体感觉、间距、布局、颜色、材质和动态语言。
- 首尾帧约束对应端点的构图、主体姿态、物体状态、光照和可见布局；分镜参考约束原定视点、主体位置、时序与场面调度。分镜边框、标签、箭头、草图标记和注释不自动进入成片。
- 多人保持各自姓名/昵称、面部锚点、发型、服装、体型比例、屏幕侧和角色关系，不融合面部、不交换姓名、不把一人的服装或配饰移到另一人。共同说话按原定分配表达，不能把多人反应合并成无关背景人影。
- 最新已绑定/批准/替换资产是当前依据，旧版外貌、服装、构图或音轨不与新版混用。一个主体由多个素材支持时逐项明确来源职责，身份、动作、风格、场景、分镜、音色和原音复用互不污染。

### 声音、数字人、口型与 MV

- 明确声音属于画内对白、画外角色声音、旁白、演唱、物理拟音、环境声、角色可听音乐还是观众配乐；声音与锁定文本分开保存。稳定说话人身份贯穿当前段，跨段继承已定姓名、声源、声线、语言和声音参考。
- 新配音固定每秒4字；汉字、字母与数字计数，标点和空白不计，独立停顿与倾听反应另计。长句只在起说节拍引用一次，并说明持续到哪一时点；后续写继续发声、呼吸或闭口，不在结尾再次粘贴原话。
- 只有原计划明确可见说话、唱歌、说唱或对口型时才写同步嘴型、下颌开合、脸颊/下巴咬字、呼吸时机、眼神强度、头部节奏及原有手势重音。人物肖像和音频同时存在不自动授权嘴型同步，先看已定声源和表演职责。
- 面部中心表演保持原有小幅头动、眨眼、克制表情与呼吸，不为数字人补舞蹈、行走、无关手势或切镜。只要画外音时可见角色不做口型同步；原定静默等待或没有词语时不创作发言。
- 歌曲/人声若是主表演源，按实际角色用于表演，不降成通用 BGM。仅音色、节拍或情绪参考不带入原音频台词；锁定书面台词与参考音频不同，以已确定的文字/复用规则为准，不暗中替换。
- 原音复制、复制部分窗口、复制单层、音色参考、音乐风格参考、节拍参考和完整最终音轨分别描述。未知音轨长度、内容或采样不足时不猜精确时码，不声称已经混音、变速或对齐；窗口只用已提供选择。
- MV 沿用同一已定主音频时间线和连续窗口，当前演唱行、口部/呼吸、手势重音、节拍击打写进时间线；不在多个源音频时刻之间跳跃。原定剪辑在乐句停顿、呼吸、重拍、军鼓或视觉冲击时，写清交接；可见口型跨切镜连续，不能截去锁定字句。
- 环境声与拟音具体对应原有动作和材质：接触、脚步、衣料、纸张、机械卡扣、操作反馈和呼吸等；“只保留”明确限定声源，不补无依据的环境底噪。没有支持的声源时保持无声，不用词表制造音效。
- 画内演奏/广播/手机/电视音乐归原定场景事件，观众听到的非画内配乐单独写配器、速度、节奏、能量和动态。已复用最终音轨不再加一层音乐；存在既定配乐时在人声、反应和关键音效下压低，不竞争语言信息。

### 可见文字、排版、UI 与交互

- 禁用字幕是禁止屏上文字，不删除台词、旁白、歌词或演唱。没有明确文字任务不补字幕、标语、标签、UI、标志或水印；有锁定文字且允许显示时逐字逐标点保留原语言，不能被模板翻译或缩写。
- 已有文字事件写清位置、出现/保持/退出时点、运动、对齐、层级、颜色与阅读停留，不遮挡眼睛、嘴巴、表情、产品主体、标志和真实操作区域。歌词排版对应当时表演行，不能与声音对不上。
- UI 沿用参考的布局、功能阅读顺序、核心控件含义、导航/交互逻辑和状态意义；颜色、字体、图标、按钮形状、间距、边框、填充、亮度与状态反馈使用同一系统。只继承已设计的悬停、按下、选定、禁用、READY、LOADING、进度、成功或错误状态，不编假状态填画面。
- 单行按钮、菜单项、玩家卡片、姓名、状态或标题保持单行，不随机换行、重复标签或伪造文案。已有玩家卡片保持玩家标签→姓名/昵称→状态层级、稳定屏幕侧和各自强调色；Continue/Start/Settings/Exit 等原有菜单项尺寸与排布统一。
- 主动作/状态/证据是视觉目的地，次要装饰不盖住它；按既定标题/状态→主要主题/交互→主要操作→次要信息阅读路线，设计已用 Z 形时保持玩家/状态→主视觉→菜单→行动入口的顺序。
- UI 色彩按既定主背景、面板主体、文字、功能强调和警告/危险角色分工，角色、面板、按钮、图标与状态共享色彩规则；已有接触阴影、环境反射和轮廓光维持融合，不发明光源。
- 产品文案若已定为屏幕设计元素，不挪到字幕位；保留原短句进入、第二短句接续、第一句腾位等已定动画与安全间距。主色来自实际产品/品牌，不机械套银/白/蓝；原文字不能因“通常3–5词”建议而删改。

### 产品、品牌与事实性资产
